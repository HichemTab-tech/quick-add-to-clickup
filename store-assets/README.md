### Description

Quick Add to ClickUp helps you capture tasks the moment you find them—without interrupting your flow.

Select text, right-click a link or image, or use any webpage and instantly create a task in the ClickUp List of your choice. Configure multiple quick actions such as “Add to Inbox,” “Save for Later,” or “Send to Work,” each with its own destination and task settings.

Features:

- Create ClickUp tasks directly from Chrome’s context menu
- Configure multiple quick actions for different Lists and workflows
- Use selected text, page titles, links, images, and URLs in task templates
- Set an assignee, priority, status, tags, and destination List per action
- Automatically discover your ClickUp Workspaces and Lists
- Optionally open a task immediately after creating it
- Receive a clear success or error notification

Quick Add to ClickUp is designed as a focused personal productivity tool. It has no analytics, advertising, intermediary server, or runtime dependencies. Your personal ClickUp token and action settings remain in your local Chrome profile, and task data is sent directly to ClickUp only when you choose a quick action.
